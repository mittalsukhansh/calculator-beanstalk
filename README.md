# AWS Elastic Beanstalk CI/CD

A Flask application demonstrating:

- Elastic Beanstalk deployment
- Blue-green deployment
- CNAME swapping
- Zero observed downtime during rollback
- Staging and production configuration
- Health monitoring
- GitHub CI/CD integration

## Endpoints

- / - Application version
- /health - Application health
- /info - Environment configuration

## Platform

Python 3.11 on Amazon Linux 2023
